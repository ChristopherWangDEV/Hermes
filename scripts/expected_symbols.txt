# Hermes 原生层导出符号清单（唯一的 ABI 真相源之一，另一半是 native/include/hermes_abi.h）
#
# 用途：scripts/build.sh 与 tests/guard/guards_test.go 会把真实的
#       build/libhermes_native.a 里的 hm_* 符号和这份清单做**双向** diff：
#         · 少一个 → 功能缺失（链接期才炸，或者更糟：运行期才炸）
#         · 多一个 → 有人给原生层偷偷加了职责，本项目的语言分工已被腐蚀
#
# 排序：LC_ALL=C sort。名字已去掉 Mach-O 的前导下划线，因此 Linux 也能直接用。
#       **顺序不参与校验**：两个消费者都是 sort -u / map 集合比较（D7 顺手改的
#       注释——原文声称有排序要求，实际两个消费者都不看顺序）。
#
# ---- Rust（19 个：5 件事 + 1 个调试钩子） ----
#   版本/初始化        4 : hm_abi_version hm_abi_build_id hm_runtime_init hm_runtime_shutdown
#   敏感缓冲           5 : hm_sensitive_{new,len,read,locked,free}
#   只读视图           4 : hm_view_{new,slice,borrow,free}
#   哈希链             2 : hm_chain_{hash,final}
#   哈希工具           1 : hm_sha256（此前注释漏计，D7 修正）
#   目标文件解析       2 : hm_objfile_dynamic_libs（不可信二进制：只做边界检查后的切片访问）
#                          hm_objfile_symbol_state（符号三态：缺失/已定义/未定义）
#   调试钩子（T03）    1 : hm_debug_peek
#
# ---- C / 汇编（17 个） ----
#   计数器             3 : hm_cycle_{now,freq,arch}
#   进程督导          14 : hm_spawn + 3 个生命周期（hm_proc_{wait,cancel,free}）
#                          + 10 个 getter/copier（见下）
#
# 合计 36 个（2026-11-19 增 hm_objfile_symbol_state：产物符号三态）。
#
# F-11b（v4）是一次**形态变更**，不是纯加性变更：删掉 4 个符号
# （hm_spawn_wait / hm_spawn_res_free / hm_spawn_cancel / hm_spawn_free）与
# 类型 hm_spawn_res，新增 13 个（hm_proc_{wait,cancel,free} + 10 个 getter），
# 25 → 34。这种删除走 hermes_abi.h 顶部 R8 的一次性例外 2b，唯一依据是
# "已发布消费者集合为空"（scripts/release.sh:33-65 的发布包既不含
# libhermes_native.a 也不含 native/include/hermes_abi.h）。
#
# 10 个 getter/copier（全部 out-of-line，禁止 static inline / 宏）：
#   hm_proc_get_state            句柄状态 {RUNNING, REAPED}
#   hm_proc_get_term             waitpid 状态字派生的 4 个值（一次原子读）
#   hm_proc_get_deadline         fired_cycles
#   hm_proc_copy_deadline_source "cycle" | "wall" | ""
#   hm_proc_get_setup            HM_SETUP_* 位 + setup_errno
#   hm_proc_get_sb_requested     请求位（回读，供判据②逐位比对）
#   hm_proc_get_sb_acked         正面握手位（E1 的判据）
#   hm_proc_get_sb_ignored       "请求了但没施加"位（F-11 既有）
#   hm_proc_copy_stdout          两阶段字节流拷贝
#   hm_proc_copy_stderr          同上
